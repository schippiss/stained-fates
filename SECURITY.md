# Подключение через SillyTavern · 0.2.1

Расширение использует штатный `ConnectionManagerRequestService.sendRequest`. Отдельных полей ключа, копирования секретов, собственного fetch или серверного модуля в runtime нет. В настройках Таро сохраняются ID профиля, флаг включения и параметры гадания. Поддерживаются профили Chat Completion с выбранной моделью.

## Ключи и получатели

Подключение и ключами управляет SillyTavern. Для обычных API он использует штатное серверное хранилище. Настройки обратного прокси могут хранить пароль иначе; расширение не меняет этот механизм и не обещает отдельный ключ для каждого профиля. В проверенном ST профили одного провайдера могут использовать общий активный ключ.

Вопрос, ограниченный контекст чата, описание персонажа и лор передаются штатной службе ST для отправки выбранному API. В GitHub, автору расширения и аналитику эти данные кодом Таро не отправляются. Изображения и значки поставляются локально, внешних JS/CDN нет.

Карты и цитаты сохраняются в метаданных чата. Пользовательские изображения — в IndexedDB. Секреты не копируются в эти данные или собственные настройки Таро. При миграции сохраняются только известные параметры гадания. Старые серверные записи экспериментального модуля автоматически не удаляются.

## Запросы и ограничения

Таро не активирует профиль, не переключает модель основного чата и не меняет ключи ST. Используются два сообщения — системная инструкция и JSON с контекстом; без ролевого пресета, с отдельным лимитом токенов. Если профиль удалён или недоступен, запрос отклоняется без перехода на другое подключение.

Ожидание ограничено 90 секундами, отмена передаётся штатной службе. Полученный текст ограничен 32000 символами и выводится через textContent. Это ограничение после получения ответа: сетевые лимиты, HTTPS, перенаправления, хранение ключей и серверные журналы зависят от ST и настроек пользователя. Ошибки службы заменяются фиксированным сообщением без сырых диагностических данных провайдера.

Администратор ST и скрипты того же origin — доверенная сторона. Штатный secrets.json не является зашифрованным сейфом; пользовательские данные, резервные копии и экспорты с секретами нельзя публиковать. Упаковка расширения использует явный список исходников без пользовательских данных.

## Проверки

`npm test`: логика карт и подтверждений, фильтрация профилей, отсутствие изменения основного подключения, параметры вызова службы, удалённые профили, отмена, ограничения текста и безопасные ошибки. Служба ST в автоматических тестах заменена тестовым объектом; её интерфейс сверён с локальным исходным кодом SillyTavern. Реальные платные запросы для проверки не отправлялись.
